# Otomat Otomasyonu Projesi (C Dili)

C programlama dili ile yazılmış, verileri saklayabilen otomat simülasyonları.

Bu repo projenin iki farklı versiyonunu içerir:

**OTOMAT 1**
* Verileri basit dizilerde tutar.
* Stok takibi için metin dosyası (`stoklar.txt`) kullanır.

**OTOMAT 2**
* Verileri `struct` yapısı altında (ID, Ad, Fiyat, Stok) toplar.
* Veri tabanı olarak binary dosya (`urunler.dat`) kullanır.
* `otomat.h` kütüphanesi ile modüler çalışır.
